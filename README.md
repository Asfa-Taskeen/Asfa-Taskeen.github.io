# Asfa Taskeen — Personal Portfolio

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript. The design uses a soft pink, lavender and purple palette and includes an illustrated hero panel, skills, projects, education and contact links.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling and visual design
- `script.js` — rotating role text and mobile navigation

## Publish with GitHub Pages
1. Open your portfolio repository on GitHub.
2. Upload all three website files (`index.html`, `style.css`, `script.js`) to the repository's **root** (not inside another folder).
3. Commit the changes to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
6. Wait for GitHub Pages to finish deploying, then refresh your site.

For the user-site repository `Asfa-Taskeen.github.io`, the expected URL is `https://asfa-taskeen.github.io/`.

## Before publishing
- Confirm your GitHub username and project repository names are correct.
- The Password Strength Checker project link is set to `https://github.com/Asfa-Taskeen/password-strength-checker`. Change it if your repository uses a different name.
- LogSentinel Mini SOC is labelled **In progress** and intentionally has no public project link yet.
- The hero portrait is a CSS illustration, so no separate image file is required.
- Google Fonts are loaded online; system sans-serif fonts will be used if offline.
